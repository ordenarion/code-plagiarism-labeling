# code-plagiarism-labeling
Сервис для коллективной разметки пар студенческого кода на наличие плагиата. Сервис разработан с целью упростить и ускорить процесс аннотирования данных для задач по обнаружению плагиата в программном коде.
## Доступный функционал и возможности:
- Загрузка архива с `.txt`-файлами студенческих работ
- Автоматическая генерация пар на сравнение
- Интерфейс для быстрой разметки "плагиат / не плагиат"
- Поддержка коллективной разметки (аналогично Яндекс.Толоке)
- Разметка сразу нескольких пар одновременно
- Хранение всех данных в базе PostgreSQL (в Docker)

## Основные страницы
![image](https://github.com/user-attachments/assets/17615405-6de2-4860-a9b4-05a134e6aea3) <br> <br>
Проект включает несколько ключевых страниц, реализующих полный цикл работы с данными:
###  Загрузка данных:
Позволяет загружать архив с `.txt`-файлами студенческих работ. После загрузки автоматически формируются пары документов для аннотации.
![image](https://github.com/user-attachments/assets/fc2cba38-286a-45b5-9373-c714e09dfc1c)
### Список работ: 
Отображает загруженные работы. Администраторы могут удалять ненужные или ошибочные файлы из базы.
![image](https://github.com/user-attachments/assets/d1b7c4f4-c1dc-4483-8778-4b9c94812a33)
### Разметка пар
Основная страница для аннотации. Пользователи видят пары работ, делают пометки о наличии/отсутствии плагиата и могут добавлять комментарии. Также в рамках данной страницы есть возможность экспорта из базы всей необходимой информации.
![image](https://github.com/user-attachments/assets/517282cb-502f-413d-b784-ca04efece43d)
### Управление ролями пользователей
Система поддерживает разграничение прав доступа. <br> <br>
*Администраторы*:
- Добавляют и управляют пользователями
- Назначают роли
- Удаляют работы из базы при необходимости <br> <br>

*Обычные пользователи*:
- Размечают пары
- Добавляют комментарии
- Просматривают свои задания

## Стек технологий
- **Streamlit** — реализация интерфейса загрузки, разметки и управления данными.
- **PostgreSQL** — реляционная база данных, в которой хранятся все загруженные работы, пары и результаты разметки.
- **SQLAlchemy** — ORM-библиотека для работы с PostgreSQL.
- **Docker** — развертка базы данных.

## Запуск
```bash
pip install -r requirements.txt
```

